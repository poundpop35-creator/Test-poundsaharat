# คลังรายบทและชุดรวม 100 ข้อ

## โครงสร้าง

- `index.html` แสดงครบ 9 หน่วยงาน แยกจากคลังกลาง ทุกหน่วยงานมีทางเข้าแยกบทและชุดรวม
- `question-bank.html?agency=<id>` ใช้หน้าฝึกเดียวกันสำหรับ 9 หน่วยงานและ `central`
- `bank-core.js` ตรวจข้อมูล สุ่มข้อสอบ สลับตัวเลือกโดยรักษาข้อที่อ้างตำแหน่ง ตรวจคำตอบ และจัดการสถานะ
- `question-banks/<id>.json` เก็บบทอ่าน คำถาม เฉลย มาตรา และข้อมูลต้นทาง
- `exam-14.html` เลิกแสดงหลักสูตรรายวันแล้ว แต่ลิงก์บทเก่าจะนำไปยังบทของหน่วยงานนั้น
- ลิงก์ `energy-sprint.html` ที่ไม่มี hash เปิดหน้าบทพลังงานใหม่ ส่วน `#resume` และ `#dashboard` ยังเปิดชุดเก่าเพื่อรองรับความคืบหน้าเดิม

## สร้างข้อมูลและตรวจงาน

```sh
npm ci --ignore-scripts
npm run build:banks
npm test
```

`scripts/build-chapter-banks.cjs` สร้างคลังหน่วยงานจากข้อมูลเดิม ส่วน `scripts/build-central-bank.cjs` รวมไฟล์กฎหมายกลางสองส่วนที่แต่งและตรวจทานแยกกัน หลังแก้ fragment ต้องสร้าง `central.json` ใหม่ด้วย

คลังหน่วยงานรวม 5,307 ข้อใน 100 บท บทอ่านจากหลักสูตรเดิมของพลังงานและสรรพากร 28 บท พร้อมโจทย์เดิม 56 ข้อ ย้ายมาจัดตามเนื้อหาแล้ว ข้อที่ข้อความไม่ครบหรือตัวเลือกเสียรูป 33 รายการ และกลุ่มโจทย์ซ้ำที่เฉลยขัดกัน 23 กลุ่ม ไม่เข้าสู่ชุดใหม่ รายละเอียดต้นทางอยู่ใน `question-banks/manifest.json` ข้อมูลเดิมยังเก็บไว้สำหรับตรวจย้อนหลัง

ชุดรวมที่จัดไว้มีชุดละ 100 ข้อและไม่มีข้อซ้ำระหว่างชุดของคลังเดียวกัน แต่ละชุดกระจายหลายบท ข้อที่เหลือจากการหาร 100 อยู่ในบทและการสุ่มชุดใหม่ การสุ่มชุดใหม่ไม่ซ้ำภายในชุด แต่สามารถซ้ำกับชุดที่เคยทำมาแล้วได้ ไม่มีการนำข้อสอบต่างหน่วยงานมาปะปนกัน

## ขอบเขตการตรวจเนื้อหา

ข้อสอบกลางใหม่ 200 ข้อแบ่ง 8 พ.ร.บ. ฉบับละ 25 ข้อ มีบทอ่าน เฉลย มาตรารายข้อ และลิงก์เอกสารราชการ ตรวจแหล่งเอกสารวันที่ 25 พฤศจิกายน 2569 และตรวจทานข้ามชุดเพื่อหาข้อกำกวมหรือคำตอบถูกได้มากกว่าหนึ่งตัวเลือก

1. ข้อมูลข่าวสารของราชการ พ.ศ. 2540 — สำนักงานคณะกรรมการข้อมูลข่าวสารของราชการ
2. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 — สำเนาราชกิจจานุเบกษาที่กรมประชาสัมพันธ์เผยแพร่
3. การปฏิบัติราชการทางอิเล็กทรอนิกส์ พ.ศ. 2565 — สำนักงานพัฒนารัฐบาลดิจิทัล
4. มาตรฐานทางจริยธรรม พ.ศ. 2562 — สำนักงาน ก.พ.
5. การจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 — ราชกิจจานุเบกษาและสำเนา สขร.
6. วิธีการงบประมาณ พ.ศ. 2561 — สำนักงบประมาณ
7. วินัยการเงินการคลังของรัฐ พ.ศ. 2561 — ราชกิจจานุเบกษา
8. ระเบียบบริหารราชการแผ่นดิน พ.ศ. 2534 รวมแก้ไขถึงฉบับที่ 8 — สำนักงาน ก.พ.ร. และสำเนาจากหน่วยงานรัฐ

ชื่อฉบับ ขอบเขตมาตราที่ตรวจ URL และวันที่ตรวจอยู่ใน `sources` ของแต่ละคลัง ไม่ควรตีความวันที่ตรวจว่าเป็นการรับรองว่ารวมกฎหมายลำดับรองหรือกฎหมายเฉพาะทุกฉบับแล้ว ข้อสอบหลีกเลี่ยงวงเงิน อัตรา และรายชื่อผู้ดำรงตำแหน่งที่เปลี่ยนได้ รวมทั้งระบุข้อยกเว้นที่มีผลต่อคำตอบในตัวโจทย์

ข้อสอบหน่วยงานที่นำมาจัดใหม่มี `sourceStatus: "existing"` การย้ายข้อมูลและตรวจโครงสร้างไม่ได้เท่ากับตรวจข้อเท็จจริงหรือกฎหมายใหม่ครบทั้งคลัง ส่วนข้อสอบกลางที่ตรวจตัวบทมี `sourceStatus: "checked"`

## ความคืบหน้าในเครื่อง

หน้าใหม่ใช้ `chapter-bank:<agency>:v1` จัดเก็บชุดที่ทำค้าง ประวัติ 30 ครั้งล่าสุด บทที่อ่านแล้ว และคำตอบข้อเขียน โดยไม่เขียนทับคีย์ของหน้าฝึกเดิม คำตอบข้อเขียนและบันทึกจาก `exam14:rd-energy:v1` นำมาแสดงตามบทเดิมเมื่อยังไม่มีฉบับใหม่กว่า หากเบราว์เซอร์ปิดการบันทึก หน้าฝึกยังใช้ได้พร้อมแจ้งข้อจำกัด

ความคืบหน้าแยกตามเครื่องและเบราว์เซอร์ ไม่ได้ซิงก์ข้ามอุปกรณ์
